## 上线前独立运维门槛

- 当前 `IDataProtection` key ring 未在 Compose 中显式持久化。容器替换后可能无法解密既有 `BankCardProtected`，会阻断工资锁定/发放。
- 本功能没有擅自改变生产密钥或部署拓扑。上线前必须先安全迁出现有 key ring，再配置持久卷并做旧银行卡解密与备份恢复演练；不能直接挂空卷后声称完成迁移。
