# 项目会议记录：业务边界

## 做什么

- 为所有已登录且资料完整的用户提供统一的项目会议记录页面。
- 用户选择启用项目和任意会议日期，填写地点、参会人员、需求内容和工作重点。
- 所有用户查看、创建和编辑全部会议记录；只有管理员可以删除。
- 选择一个项目导出该项目全部未删除会议记录，一条记录对应一个 Excel 工作表。
- 每周生成会议记录全量备份，并永久保存到服务器独立持久目录。

## 核心业务对象

- 会议记录：归属项目和会议日期，保存创建人、最后编辑人、删除人、时间戳及并发令牌。
- 参会人员：姓名、单位、职务、电话，隶属于一条会议记录并保持顺序。
- 会议事项：类型为“需求内容”或“工作重点”，保存内容、状态、截止日期、负责人并保持顺序。
- 备份快照：每周不可覆盖的领域全量快照，包含 manifest、校验值和全部会议记录数据。

## 数据归属与权限

- 会议记录归属项目，不归创建人私有；同一项目、同一日期允许多条记录。
- 所有认证用户具有相同的查看、新建和编辑权限。
- 创建人只表示首次录入者；后续编辑只更新最后编辑人，不改变创建人。
- 删除仅限管理员，并保存删除人和删除时间；普通列表和项目导出排除已删除记录。
- 停用项目不能用于新建记录；既有停用项目记录仍可查看和编辑，但不能改到另一个停用项目。

## 审计与并发

- 会议记录无草稿、提交、审批、驳回或归档状态，首次保存即有效。
- 创建、编辑、删除、导出和备份均有审计或结构化日志。
- 审计仅记录项目、日期、数量和操作人等元数据，不复制会议正文和电话号码。
- 编辑和删除均校验并发令牌，不匹配时返回 409。

## 备份边界

- 每周日北京时间 02:00 对全部会议记录执行一次领域全量备份，包含已软删除记录。
- 服务错过计划时间后，在恢复运行时补做当周备份；同一周只保留一个成功快照。
- 备份文件原子写入、不可覆盖、不自动删除，并存放在独立服务器目录或 Docker 持久卷。
- 本功能不替代 PostgreSQL、附件卷和服务器磁盘的整机灾备；运维仍需备份数据库和持久卷。
- 本期提供备份生成和完整性验证，不提供页面恢复、自动恢复或跨服务器复制。

## 明确不做

- 不接入报销、餐补、支付、审批或发放流程。
- 不维护项目成员关系。
- 不提供附件、评论、通知、签字或正文版本恢复。
- 不改变现有周报权限、日期规则和接口。
