# 项目会议记录：需求说明

## REQ-001 共享会议记录列表

- 优先级：Must
- 业务目的：让团队统一查看项目会议记录。
- 影响角色：全部已登录且资料完整的用户。
- 输入：项目、会议日期范围、分页。
- 输出：会议日期、项目、地点、创建人、最后编辑人、更新时间和内容概览。
- 默认规则：所有用户看到相同数据集，排除已删除记录，不按创建人过滤。

## REQ-002 创建会议记录

- 优先级：Must
- 输入：启用项目、任意会议日期、会议地点、参会人员、会议事项。
- 输出：新会议记录及审计日志。
- 默认规则：同项目、同日期允许创建多条记录，不设置业务唯一键。

## REQ-003 编辑会议记录

- 优先级：Must
- 输入：完整会议记录内容和 `ConcurrencyToken`。
- 输出：更新后的记录、最后编辑人、更新时间和新并发令牌。
- 默认规则：任意认证用户均可编辑任意未删除会议记录；创建人不变。

## REQ-004 日期规则

- 优先级：Must
- 输入：会议日期及筛选日期范围。
- 输出：接受任意有效日历日期，不沿用周报的周一限制。
- 默认规则：只采集日期，不采集具体时分。

## REQ-005 结构化会议内容

- 优先级：Must
- 输入：会议地点；参会人员列表；统一会议事项列表。
- 输出：按录入顺序保存和展示。
- 字段：参会人员包含姓名、单位、职务、电话；会议事项包含需求内容、自由文本状态、截止日期、负责人。
- 默认规则：至少填写一名参会人员和一条会议事项。

## REQ-006 按项目全量导出

- 优先级：Must
- 输入：必选项目。
- 输出：一个 `.xlsx` 文件，包含该项目全部未删除会议记录，不受页面日期筛选和分页影响。
- 工作表：每条记录一个工作表，按会议日期、创建时间、记录 ID 从旧到新稳定排列。
- 样式：参考 `会议记录.xlsx` 的标题、分区、合并单元格、粗边框、字体和 A4 纵向打印设置。
- 默认规则：工作表名称包含日期和序号并保证合法、不重名；项目无会议记录时返回明确业务提示。

## REQ-007 审计与并发保护

- 优先级：Must
- 输出：创建、编辑、删除、导出审计；编辑或删除并发冲突返回明确 409 错误。
- 不做事项：审计不保存正文副本，本期不提供可恢复的正文版本历史。

## REQ-008 页面与导航

- 优先级：Must
- 输出：主导航新增“会议记录”；页面支持筛选、分页、新建、编辑、管理员删除和按项目导出。
- 依赖事项：沿用现有个人资料完整性路由限制和 Element Plus 交互模式。

## REQ-009 管理员删除

- 优先级：Must
- 输入：会议记录 ID、`ConcurrencyToken` 和管理员身份。
- 输出：记录标记删除，保存删除人、删除时间并写入审计。
- 权限：普通用户删除返回 403；重复删除返回 404 或明确的已删除结果。
- 默认规则：删除不物理移除主记录、参会人员或会议事项。

## REQ-010 每周全量永久备份

- 优先级：Must
- 业务目的：在服务器保留可校验、可供后续恢复开发使用的会议记录历史快照。
- 调度：每周日北京时间 02:00 执行；错过后在服务恢复时补做；同一周幂等。
- 范围：全部会议记录，包括参会人员、会议事项、创建/编辑/删除元数据和已删除记录。
- 输出：不可覆盖 ZIP，包含版本化 JSON 和 manifest/checksum；成功后记录文件名、数量、大小和哈希。
- 存储：独立配置目录；容器部署挂载独立持久卷；不设置自动清理或保留期限。
- 失败处理：保留旧备份，删除未完成临时文件，记录错误并在下一次检查时重试。
- 不做事项：本期不提供 UI 恢复、自动恢复、异地复制或整库备份。
