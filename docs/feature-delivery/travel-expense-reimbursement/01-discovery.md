# 差旅报销 Web：调研记录

## 项目现状

当前工作目录为空，尚无可复用的前后端、数据库、身份认证、文件存储或部署规范。因此本轮无法做“在既有项目内二次开发”的技术适配判断。

## 开源候选

### Frappe HR / ERPNext Expense Claim

- 定位：完整开源 HRMS，包含员工费用报销、预支、分级审批、会计集成和移动端。
- 可复用：费用申报、附件、部门审批人、审批流、付款记录、审计、角色权限和报表。
- 不匹配：核心模型为“费用条目 + 费用申请单”，不是“去程 + 回程 + 住宿”强约束的行程对象；公开注册的三态策略和注册人工审批需定制。
- 技术与部署：Frappe Framework，Python/JavaScript，Docker 自托管可行，但有完整 HR/薪酬/会计体系的运行与升级负担。
- 许可证：GPL-3.0；若要向外分发或形成闭源交付，应先做许可证合规评估。

### Odoo Community Expenses（hr_expense）

- 定位：通用 ERP 的员工费用模块；支持费用录入、票据附件、提交、经理审批、会计确认和报销。
- 可复用：费用条目、费用报告、附件、审批、会计接口、组织权限、后台配置。
- 不匹配：标准模块把交通、住宿、餐饮和办公用品都视为费用类别，缺少行程对象及三类票据完整性校验；注册审核模式需自定义模块实现。
- 技术与部署：Python/Odoo 模块机制；适合已有 Odoo 或计划同步引入 ERP 的组织。
- 许可证：Odoo 源码与 `hr_expense` 模块标注 LGPL-3；但拟安装的 OCA/第三方模块应逐项复核许可证，常见为 AGPL-3。

### Reimburse for Nonprofits

- 定位：轻量化费用采集工具，可记录住宿、地面交通、航空、餐饮等费用，并可归集到报告。
- 价值：可作为移动化凭证采集和费用分组交互的参考。
- 不建议选用：公开资料显示其面向非营利组织和个人费用记录，未证实具备你的注册策略、角色审批、行程必填校验和可持续维护能力；本轮未能确认适合生产使用的许可证与近期维护状态。

## 初步结论

市场上存在成熟的“费用条目—报销单—审批—付款”开源能力，但没有发现可以不改造便完全满足“行程三票据结构 + 三态注册治理”的成熟开源项目。
