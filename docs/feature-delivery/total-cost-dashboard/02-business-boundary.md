# 总费用看板：业务边界

- 角色：管理员。所有数据只读；不新增审批、发放和编辑操作。
- 工资：ReadyForPayout/Completed 期间内 Pending/Paid 明细的 NetPay。
- 报销：Approved 主记录的当前版本 TotalAmount，发放状态 Pending/Paid。
- 餐补：已批准父单当前版本中 Approved 且金额已核定的餐补，按餐补自身 Pending/Paid 状态统计；父单未批准或已取消均不计入。
- 人员按用户 ID 合并，保留停用人员的历史费用，不依赖仅启用申请人目录。
- 按项目查看或筛选具体项目时排除工资，并在界面说明；工资仅出现在全局、分类和人员视图。
- 已发放 + 待发放 = 总费用，三类费用互斥相加。
- 不涉及真实转账、税务口径、公司承担社保、项目分摊、归档绑定、附件变化、数据库写入及迁移。
- 无时间筛选与趋势统计；明细来源中的工资月份仅用于识别原始工资记录。
