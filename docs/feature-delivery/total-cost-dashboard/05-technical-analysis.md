# 总费用看板：技术分析

- 主 Agent 完成分析，未启用 subagent（用户未授权，也无需并行分析）。
- 工资与报销以用户 ID 关联；工资缺少项目关系，项目视图必须排除工资。
- 报销版本 TotalAmount 已是费用明细合计，无需连 ExpenseItems 再求和。餐补独立一条来源记录。
- 新查询不复用旧报销看板的状态筛选，因为旧看板允许待审批与驳回。
- 三类费用投影为统一只读行后 UNION ALL，可在数据库执行筛选、分组与分页；需要验证 Npgsql SQL 翻译。
- 人员/项目候选来自有效费用集合，避免仅获取前 100 个启用申请人而遗漏停用用户和管理员工资。
- 工资只读详情使用已有管理员期间详情接口；报销/餐补复用 ClaimDetailDrawer。
