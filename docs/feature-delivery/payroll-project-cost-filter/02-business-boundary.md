# 已确认业务边界

- 管理员为每条员工月工资单选出资项目；不分摊。草稿可暂不选，锁定前必须选启用项目。
- 用户明确要求：历史工资不自动指定项目，历史有效工资重置为草稿；发放登记和工资审计均不保留。已取消期间维持取消，避免同月有效期间唯一约束冲突。
- 一次性迁移删除工资发放凭据、清除工资发放状态和时间、重置有效期间状态及锁定/完成时间、刷新并发令牌；清除工资领域审计，不影响报销与餐补。此数据重置不能通过 Down 恢复。
- 不创建已发工资单独补项目接口；统一通过草稿编辑、锁定、重新登记发放。
- 时间使用起止月份：工资按工资月，报销与餐补按报销提交月（中国时区），包含首尾月份，默认不限时间。
- 所有卡片、分组和明细使用同一过滤；历史有效工资回到草稿后暂不统计，选项目且重新锁定后计入。
- 不执行生产数据库变更，不修改认证、审批与金额公式。
